# AI Resume Screener

An AI-assisted web application for screening, comparing, and ranking multiple resumes against a given job description.

## 📌 Project Overview

The AI Resume Screener is a web-based application designed to simplify the initial resume screening process.

Recruiters may receive many resumes for a single job position, making manual comparison time-consuming. This application allows users to upload multiple resumes and provide a job description. The system analyzes the available resume information, compares candidate skills and experience with the job requirements, calculates screening results, and ranks candidates.

The application also provides candidate details and screening history through a user-friendly interface.

> Note: The system is intended to assist with initial candidate screening. Final recruitment decisions should be made by a human recruiter.
